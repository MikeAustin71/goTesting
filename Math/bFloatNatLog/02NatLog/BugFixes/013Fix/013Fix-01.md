## 3. 013Fix — ExpoBigFloat design

### 3.1. Scope for this step

To keep this step focused and robust, we’ll implement:

- **Integer exponentiation** for `*big.Float` bases:
  - Compute $x^n$ where:
    - $x$ is a `*big.Float`
    - $n$ is a signed integer (`int64`)
- Negative exponents are supported via: $$ xn = \frac{1}{x{|n|}} \quad \text{for } n < 0 $$

This gives you:

- A precise, high‑performance exponent function for all the typical scaling operations you’ll need in the AGM kernel and related mechanics.
- A clean extension point later if you decide to add real‑valued exponents via $\exp$/$\ln$.

### 3.2. Algorithm

We’ll use **exponentiation by squaring**:

- If $n = 0$, return $1$.
- If $n > 0$:
  - Maintain:
    - `result` (starts at $1$)
    - `base` (starts as $x$)
  - While $n > 0$:
    - If $n$ is odd, `result = result * base`
    - `base = base * base`
    - $n = \lfloor n / 2 \rfloor$
- If original $n < 0$, compute $x^{|n|}$ as above, then return its reciprocal.

All operations are done at a **working precision** slightly above `precBits`, then rounded down to `precBits` at the end—mirroring your `SqrtBigFloat` style.

## 4. 013Fix — ExpoBigFloat implementation in bigFloatMath.go

```go
// ***********************
// ** bigFloatMath.go   **
// ** 013Fix additions  **
// ***********************

package naturalLogCalcs

import (
	"math/big"
)

type BigFloatMath struct{}

// ExpoBigFloat
//
// 013Fix
//
// Computes x^n for a *big.Float base x and integer exponent n,
// using exponentiation by squaring.
//
//   - x must be non-nil
//   - precBits is the desired output precision in bits
//   - n may be negative, zero, or positive
//
// On success, returns a *big.Float with precision 'precBits'.
func (bFloatMath *BigFloatMath) ExpoBigFloat(
	x *big.Float,
	n int64,
	precBits uint) (*big.Float, error) {

	ePrefix := "BigFloatMath.ExpoBigFloat()"

	if x == nil {
		return nil, &InputPtrNilError{
			ErrPrefix:     ePrefix,
			ErrContext:    "",
			ParameterName: "'x'",
		}
	}

	// Handle exponent == 0: x^0 = 1 (even if x == 0, we follow the usual convention)
	if n == 0 {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(precBits).
			SetFloat64(1.0), nil
	}

	// Working precision slightly above requested precision
	workingPrec := precBits + 8

	newF := func() *big.Float {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(workingPrec)
	}

	// Copy base to working precision
	base := newF().Set(x)

	// Track sign of exponent
	negExponent := n < 0
	if negExponent {
		n = -n
	}

	// result = 1
	result := newF().SetFloat64(1.0)

	// Exponentiation by squaring
	for n > 0 {
		if (n & 1) == 1 {
			result.Mul(result, base)
		}
		base.Mul(base, base)
		n >>= 1
	}

	// If exponent was negative, take reciprocal
	if negExponent {
		one := newF().SetFloat64(1.0)
		// Guard against division by zero
		if result.Sign() == 0 {
			return nil, &FuncReturnError{
				ErrPrefix:  ePrefix,
				ReturnFunc: "ExpoBigFloat(x, n, precBits)",
				ErrContext: "Attempted reciprocal of zero for negative exponent.",
				ErrMessage: "division by zero",
			}
		}
		result.Quo(one, result)
	}

	// Round to requested precision
	out := new(big.Float).
		SetMode(big.AwayFromZero).
		SetPrec(precBits)

	out.Set(result)

	return out, nil
}
```

This follows your existing error patterns (`InputPtrNilError`, `FuncReturnError`) and precision style.

// naivePowBigFloat is a simple repeated-multiplication reference
// used only for testing ExpoBigFloat.
func naivePowBigFloat(x *big.Float, n int64, precBits uint) *big.Float {

	newF := func() *big.Float {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(precBits)
	}

	if n == 0 {
		return newF().SetFloat64(1.0)
	}

	neg := n < 0
	if neg {
		n = -n
	}

	result := newF().SetFloat64(1.0)
	base := newF().Set(x)

	for i := int64(0); i < n; i++ {
		result.Mul(result, base)
	}

	if neg {
		one := newF().SetFloat64(1.0)
		result.Quo(one, result)
	}

	return result
}
