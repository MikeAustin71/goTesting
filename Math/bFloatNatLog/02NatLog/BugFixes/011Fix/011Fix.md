## 1. 010Fix AGM source code (`naturalLogAGM.go`)

```go
// *************************
// **   naturalLogAGM.go  **
// *************************
package naturalLogCalcs

import (
	"math/big"
)

// naturalLogAGM
//
// 010Fix version:
// - Public kernel: lnAGMDirect(x, prec)
// - Internal mantissa kernel: lnAGMMantissa(m, prec)
//   (currently delegates to Taylor; can later be replaced
//    by a true AGM iteration without changing the API).
type naturalLogAGM struct {
	shared naturalLogShared
	mech   naturalLogSharedMechanics
}

// lnAGMDirect
//
// Computes ln(x) using a two–stage process:
//
// 1. Normalize x into mantissa m and exponent k such that
//    x = m * 2^k with m in [0.5, 1).
// 2. Compute ln(x) = ln(m) + k * ln(2).
//
// The mantissa kernel is lnAGMMantissa(m, prec), which is
// currently implemented via the Taylor kernel for 010Fix.
func (agm *naturalLogAGM) lnAGMDirect(
	x *big.Float,
	precBits uint) (*big.Float, error) {

	ePrefix := "naturalLogAGM.lnAGMDirect()"

	if x == nil {
		return nil, &InputPtrNilError{
			ErrPrefix:     ePrefix,
			ParameterName: "'x'",
		}
	}

	if x.Sign() <= 0 {
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix,
			ReturnFunc: "lnAGMDirect(x, precBits)",
			ErrMessage: "input parameter 'x' must be greater than zero",
		}
	}

	// Small safety margin for intermediate work
	workPrec := precBits + 16

	// Normalize x = m * 2^k with m in [0.5, 1)
	m := agm.shared.newFloat(workPrec)
	k := x.MantExp(m) // m now in [0.5, 1)

	// Compute ln(m) using the mantissa kernel
	lnMant, err := agm.lnAGMMantissa(m, workPrec)
	if err != nil {
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix,
			ReturnFunc: "lnAGMMantissa(m, workPrec)",
			ErrMessage: err.Error(),
		}
	}

	// Compute k * ln(2)
	ln2 := agm.mech.getLn2(uint(workPrec))

	kBig := agm.shared.newFloat(workPrec)
	kBig.SetInt64(int64(k))

	kLn2 := agm.shared.newFloat(workPrec)
	kLn2.Mul(kBig, ln2)

	// ln(x) = ln(m) + k * ln(2)
	resultWork := agm.shared.newFloat(workPrec)
	resultWork.Add(lnMant, kLn2)

	// Final result rounded to requested precision
	result := agm.shared.newFloat(precBits)
	result.Copy(resultWork)

	return result, nil
}

// lnAGMMantissa
//
// Mantissa kernel for ln(m) where m is in (0, 2].
//
// 010Fix implementation:
// - Validates input.
// - Delegates to the Taylor kernel lnTaylorDirect(m, precBits).
// - This function is the *only* place that needs to change
//   when a true AGM iteration is introduced.
func (agm *naturalLogAGM) lnAGMMantissa(
	m *big.Float,
	precBits uint) (*big.Float, error) {

	ePrefix := "naturalLogAGM.lnAGMMantissa()"

	if m == nil {
		return nil, &InputPtrNilError{
			ErrPrefix:     ePrefix,
			ParameterName: "'m'",
		}
	}

	if m.Sign() <= 0 {
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix,
			ReturnFunc: "lnAGMMantissa(m, precBits)",
			ErrMessage: "input parameter 'm' must be greater than zero",
		}
	}

	// 010Fix: Delegate to Taylor kernel.
	// Later, this block can be replaced by a true AGM iteration
	// without changing the public API.
	taylor := new(naturalLogTaylor)

	mCopy := agm.shared.newFloat(precBits)
	mCopy.Copy(m)

	lnM, err := taylor.lnTaylorDirect(mCopy, precBits)
	if err != nil {
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix,
			ReturnFunc: "taylor.lnTaylorDirect(mCopy, precBits)",
			ErrMessage: err.Error(),
		}
	}

	return lnM, nil
}
```

## 2. PowerPoint‑style workflow diagram (Markdown)

### Slide 1 — High‑level overview

- **Title:** Natural Logarithm via AGM Front‑End (010Fix)
- **Goal:** Compute $ \ln(x) $ for $ x > 0 $ using:
  - **Normalization:** $ x = m \cdot 2^k $
  - **Kernel:** $ \ln(m) $ via `lnAGMMantissa`
  - **Reconstruction:** $ \ln(x) = \ln(m) + k \cdot \ln(2) $

------

### Slide 2 — Input validation and setup

- **Step 1 — Validate input**
  - **Check nil:** `x == nil` → `InputPtrNilError`
  - **Check domain:** `x.Sign() <= 0` → `FuncReturnError` (“x must be > 0”)
- **Step 2 — Precision planning**
  - **Requested precision:** `precBits`
  - **Working precision:** `workPrec = precBits + 16`
  - **Shared helper:** `naturalLogShared.newFloat(workPrec)` for consistent mode/prec

------

### Slide 3 — Normalization: $ x = m \cdot 2^k $

- **Step 3 — Extract mantissa and exponent**
  - Call: `k := x.MantExp(m)`
  - Result:
    - $ m \in [0.5, 1) $
    - $ k \in \mathbb{Z} $
    - Identity: $ x = m \cdot 2^k $
- **Why this matters**
  - Keeps $ m $ in a numerically stable range for the kernel.
  - Allows reuse of a high‑precision $ \ln(2) $ constant:
    - $ \ln(x) = \ln(m) + k \cdot \ln(2) $

------

### Slide 4 — Mantissa kernel (010Fix: Taylor‑backed)

- **Step 4 — Call mantissa kernel**
  - API: `lnMant, err := lnAGMMantissa(m, workPrec)`
- **Inside `lnAGMMantissa`**
  - **Validate:** `m != nil`, `m.Sign() > 0`
  - **010Fix implementation:**
    - Copy mantissa to `mCopy` at `precBits`.
    - Delegate to Taylor kernel:
      - `taylor := new(naturalLogTaylor)`
      - `lnM, err := taylor.lnTaylorDirect(mCopy, precBits)`
- **Design intention**
  - `lnAGMMantissa` is the **single swap‑point**:
    - Today: Taylor series kernel.
    - Future: true AGM iteration (same signature, same call site).

------

### Slide 5 — Reconstruction with $ \ln(2) $

- **Step 5 — Compute $ k \cdot \ln(2) $**
  - Get high‑precision $ \ln(2) $:
    - `ln2 := mech.getLn2(uint(workPrec))`
  - Convert exponent:
    - `kBig := newFloat(workPrec); kBig.SetInt64(int64(k))`
  - Multiply:
    - `kLn2 := newFloat(workPrec); kLn2.Mul(kBig, ln2)`
- **Step 6 — Combine terms**
  - Working result:
    - `resultWork := newFloat(workPrec)`
    - `resultWork.Add(lnMant, kLn2)`
  - Final rounding:
    - `result := newFloat(precBits)`
    - `result.Copy(resultWork)`
- **Final formula**
  - $$ \ln(x) = \ln(m) + k \cdot \ln(2) $$

------

### Slide 6 — Future AGM kernel plug‑in

- **Current state (010Fix)**
  - `lnAGMMantissa(m, precBits)` delegates to:
    - `naturalLogTaylor.lnTaylorDirect(m, precBits)`
  - All existing tests (Taylor, AGM, dispatcher) pass using this structure.
- **Future upgrade path**
  - Replace only the body of `lnAGMMantissa`:
    - Implement a true AGM iteration for $ \ln(m) $ on $ m \in (0, 2] $.
    - Keep:
      - Function signature.
      - Error semantics.
      - Call sites (`lnAGMDirect`, dispatcher tests).
- **Result**
  - You get a **drop‑in AGM kernel**:
    - No changes to tests’ public behavior.
    - No changes to dispatcher or shared mechanics.
    - Only the internal mantissa kernel evolves.
