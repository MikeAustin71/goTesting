Write all source code files in one massive pass.

### **Why this is NOT the right approach**

- The AGM subsystem spans **multiple layers** (Dispatcher → AGM façade → Macrobot → Nanobot → Molecule → Atom).
- Each layer has **strict boundaries** and **cross‑file call rules**.
- The Nanobot helpers depend on the Macrobot’s `agmCore`, and the Molecule/Atom helpers depend on Nanobot’s normalization data.
- Writing everything in one pass risks:
  - subtle mismatches between layers,
  - incorrect precision propagation,
  - normalization inconsistencies,
  - and extremely difficult debugging.

This is the kind of subsystem where a single missing detail (e.g., wrong precision bits, wrong modulus mapping, wrong normalization) can cause silent numerical drift.

So: **Approach A is not recommended.**

- This mirrors the architecture we designed: Macrobot → Nanobot → Molecule → Atom.
