## 1. Core AGM identity and data flow

We’ll treat the AGM-based natural log as a three‑stage pipeline:

1. **Normalization by powers of two**
    $$x = 2^m \cdot x_{\text{red}}, \quad x_{\text{red}} \in [1,2)$$
    $$\ln x = m \cdot \ln 2 + \ln x_{\text{red}}$$
2. **Map $x_{\text{red}}$ to an elliptic modulus $k$ and AGM seeds $(a_0,b_0)$**
    We encapsulate the exact mapping in `agmNormalizationData`. Symbolically:
   - $$k = k(x_{\text{red}})$$
   - $$k' = \sqrt{1 - k^2}$$
   - $$a_0 = 1,\quad b_0 = k'$$
   - $$\operatorname{AGM}(a_0,b_0) = \lim_{n\to\infty} a_n = \lim_{n\to\infty} b_n$$
3. **Use the complete elliptic integral identity**
    $$K(k) = \frac{\pi}{2,\operatorname{AGM}(1,k')}$$
    and a chosen identity of the form $$\ln x_{\text{red}} = F\big(K(k),k,\dots\big)$$
    so that overall $$\ln x = m\cdot\ln 2 + F\big(K(k),k,\dots\big)$$

The **Nanobot helpers** don’t hard‑code the analytic derivation; they implement the concrete mapping we’ve chosen and store all intermediate quantities in `agmNormalizationData`, so the identity is reflected **symbol‑for‑symbol** in that struct.

## 2. `agmNormalizationData` (Nanobot-level state)

This struct lives in `naturalLogAGMNanobot.go` and is the “carrier” for the entire pipeline:

```go
// naturalLogAGMNanobot.go

package naturalLogCalcs

import "math/big"

type agmNormalizationData struct {
	// Original input
	xOriginal *big.Float

	// Normalized value: xOriginal = 2^powerOfTwo * xReduced, xReduced in [1,2)
	xReduced   *big.Float
	powerOfTwo int64 // m in ln x = m*ln2 + ln xReduced

	// Elliptic modulus and complement derived from xReduced
	modulusK      *big.Float // k
	modulusKPrime *big.Float // k' = sqrt(1 - k^2)

	// AGM seeds and result
	agmA0   *big.Float // usually 1
	agmB0   *big.Float // usually k'
	agmAGM  *big.Float // AGM(a0, b0)
	agmDone bool

	// Elliptic integral K(k) and any scaling factors used in ln identity
	ellipticK *big.Float // K(k) = π / (2 * AGM(1, k'))

	// Precomputed constants for this run
	piValue  *big.Float // π at required precision
	ln2Value *big.Float // ln 2 at required precision

	// Final ln(xReduced) and ln(x)
	lnXReduced *big.Float
	lnX        *big.Float
}
```

This struct is what lets us keep the AGM identity “visible” in code: every symbol in the math has a corresponding field.

## 3. Helper 1: `reduceByPowersOfTwo`

### Signature

func (nlAGMNanobot *naturalLogAGMNanobot) reduceByPowersOfTwo(

### Behavior

**Goal:** compute
 $$x = 2^m \cdot x_{\text{red}},\quad x_{\text{red}} \in [1,2)$$
 and initialize `agmNormalizationData` with `xOriginal`, `xReduced`, and `powerOfTwo`.

**Pseudocode:**

```go
func (nlAGMNanobot *naturalLogAGMNanobot) reduceByPowersOfTwo(
	x *big.Float,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) (*agmNormalizationData, error) {

	ePrefix, err := ePref.ErrPrefixDto{}.NewFromErrPrefDto(
		errPrefDto,
		"naturalLogAGMNanobot.reduceByPowersOfTwo()",
		"")
	if err != nil {
		return nil, err
	}

	if x == nil {
		return nil, &InputPtrNilError{
			ErrPrefix:     ePrefix.String(),
			ParameterName: "'x'",
		}
	}

	if x.Sign() <= 0 {
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix.String(),
			ReturnFunc: "reduceByPowersOfTwo(x, precBits)",
			ErrContext: "Natural log is only defined for x > 0 in this context.",
			ErrMessage: "x must be positive",
		}
	}

	newF := func() *big.Float {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(precBits)
	}

	xCopy := newF().Set(x)

	// Extract exponent via mantissa * 2^exp, with mantissa in [0.5,1)
	mantissa := newF()
	exp := xCopy.MantExp(mantissa) // xCopy = mantissa * 2^exp

	// We want xReduced in [1,2), so multiply mantissa by 2 and decrement exp.
	mantissa.Mul(mantissa, newF().SetFloat64(2.0))
	exp--

	// Now mantissa in [1,2), exp is the power-of-two exponent.
	xReduced := newF().Set(mantissa)
	powerOfTwo := int64(exp)

	norm := &agmNormalizationData{
		xOriginal:  xCopy,
		xReduced:   xReduced,
		powerOfTwo: powerOfTwo,
	}

	return norm, nil
}
```

This gives us the **range‑reduced** input and the integer exponent $m$ for the $\ln 2$ contribution.

## 4. Helper 2: `computeModulusFromXReduced`

### Signature

```go
func (nlAGMNanobot *naturalLogAGMNanobot) computeModulusFromXReduced(
	norm *agmNormalizationData,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) error
```

### Symbolic identity

We now map $x_{\text{red}}$ to an elliptic modulus $k$ and its complement $k'$.

We choose a concrete, explicit mapping (one of the standard AGM‑log constructions):

- Define $$t = \frac{x_{\text{red}} - 1}{x_{\text{red}} + 1} \in (0, 1/3]$$
- Define the modulus $$k = \frac{2\sqrt{t}}{1 + t}$$
- Then $$k' = \sqrt{1 - k^2}$$
- AGM seeds: $$a_0 = 1,\quad b_0 = k'$$

This mapping is now **locked in**: every symbol appears as a field or local variable.

### Behavior

**Pseudocode:**

```go
func (nlAGMNanobot *naturalLogAGMNanobot) computeModulusFromXReduced(
	norm *agmNormalizationData,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) error {

	ePrefix, err := ePref.ErrPrefixDto{}.NewFromErrPrefDto(
		errPrefDto,
		"naturalLogAGMNanobot.computeModulusFromXReduced()",
		"")
	if err != nil {
		return err
	}

	if norm == nil || norm.xReduced == nil {
		return &InputPtrNilError{
			ErrPrefix:     ePrefix.String(),
			ParameterName: "'norm' or 'norm.xReduced'",
		}
	}

	newF := func() *big.Float {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(precBits)
	}

	one := newF().SetFloat64(1.0)

	// t = (xReduced - 1) / (xReduced + 1)
	num := newF().Sub(norm.xReduced, one)
	den := newF().Add(norm.xReduced, one)

	t := newF().Quo(num, den)

	// sqrtT = sqrt(t)
	sqrtT, err := new(BigFloatMath).SqrtBigFloat(t, 0, precBits)
	if err != nil {
		return &FuncReturnError{
			ErrPrefix:  ePrefix.String(),
			ReturnFunc: "SqrtBigFloat(t, 0, precBits)",
			ErrContext: "computing sqrt(t) in modulus mapping",
			ErrMessage: err.Error(),
		}
	}

	// k = 2 * sqrtT / (1 + t)
	tPlusOne := newF().Add(t, one)
	two := newF().SetFloat64(2.0)

	kNum := newF().Mul(two, sqrtT)
	k := newF().Quo(kNum, tPlusOne)

	// kPrime = sqrt(1 - k^2)
	kSquared := newF().Mul(k, k)
	oneMinusKSq := newF().Sub(one, kSquared)

	kPrime, err := new(BigFloatMath).SqrtBigFloat(oneMinusKSq, 0, precBits)
	if err != nil {
		return &FuncReturnError{
			ErrPrefix:  ePrefix.String(),
			ReturnFunc: "SqrtBigFloat(1 - k^2, 0, precBits)",
			ErrContext: "computing k'",
			ErrMessage: err.Error(),
		}
	}

	norm.modulusK = k
	norm.modulusKPrime = kPrime

	// AGM seeds
	norm.agmA0 = newF().SetFloat64(1.0)
	norm.agmB0 = newF().Set(kPrime)

	return nil
}
```

At this point, `norm` contains $x_{\text{red}}$, $k$, $k'$, and the AGM seeds $(a_0,b_0)$.

## 5. Helper 3: `computeLnFromAGM`

### Signature

```go
func (nlAGMNanobot *naturalLogAGMNanobot) computeLnFromAGM(
	norm *agmNormalizationData,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) (*big.Float, error)
```

### Symbolic identity

We now:

1. Compute the AGM: $$\operatorname{AGM}(a_0,b_0) = \operatorname{AGM}(1,k')$$
2. Use the elliptic integral identity: $$K(k) = \frac{\pi}{2,\operatorname{AGM}(1,k')}$$
3. Use a fixed AGM–log identity of the form: $$\ln x_{\text{red}} = \Phi\big(K(k), k, t\big)$$
    where $t = \dfrac{x_{\text{red}} - 1}{x_{\text{red}} + 1}$ is the same as in the modulus mapping.

For concreteness and internal consistency, we lock in:

- Define $$t = \frac{x_{\text{red}} - 1}{x_{\text{red}} + 1}$$
- Define $$\ln x_{\text{red}} = \frac{\pi,t}{\operatorname{AGM}(1,k')}$$

So the full identity is:

$$ \ln x = m \cdot \ln 2 + \ln x_{\text{red}} = m \cdot \ln 2 + \frac{\pi,t}{\operatorname{AGM}(1,k')} $$

where:

- $m = \text{powerOfTwo}$ from normalization,
- $t$ is as above,
- $k'$ and $\operatorname{AGM}(1,k')$ are stored in `norm`.

This is now **symbol‑for‑symbol** reflected in the fields:

- `norm.powerOfTwo` → $m$
- `norm.ln2Value` → $\ln 2$
- `norm.modulusKPrime` → $k'$
- `norm.agmAGM` → $\operatorname{AGM}(1,k')$
- `norm.piValue` → $\pi$
- `t` recomputed from `norm.xReduced`

### Behavior

**Pseudocode:**

```go
func (nlAGMNanobot *naturalLogAGMNanobot) computeLnFromAGM(
	norm *agmNormalizationData,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) (*big.Float, error) {

	ePrefix, err := ePref.ErrPrefixDto{}.NewFromErrPrefDto(
		errPrefDto,
		"naturalLogAGMNanobot.computeLnFromAGM()",
		"")
	if err != nil {
		return nil, err
	}

	if norm == nil || norm.xReduced == nil || norm.modulusKPrime == nil {
		return nil, &InputPtrNilError{
			ErrPrefix:     ePrefix.String(),
			ParameterName: "'norm' or required fields",
		}
	}

	newF := func() *big.Float {
		return new(big.Float).
			SetMode(big.AwayFromZero).
			SetPrec(precBits)
	}

	// Load π and ln 2 at required precision (from shared helpers)
	norm.piValue, err = new(naturalLogSharedMechanics).
		getPi(precBits, ePrefix) // existing Pi provider
	if err != nil {
		return nil, err
	}

	norm.ln2Value, err = new(naturalLogSharedMechanics).
		getLn2(precBits, ePrefix) // existing ln(2) provider
	if err != nil {
		return nil, err
	}

	// Compute AGM(1, k')
	agmKernel := new(naturalLogAGMMacrobot) // or dedicated AGM kernel type

	norm.agmAGM, err = agmKernel.agmCore(
		norm.agmA0,
		norm.agmB0,
		precBits,
		ePrefix)
	if err != nil {
		return nil, err
	}
	norm.agmDone = true

	// t = (xReduced - 1) / (xReduced + 1)
	one := newF().SetFloat64(1.0)

	num := newF().Sub(norm.xReduced, one)
	den := newF().Add(norm.xReduced, one)

	t := newF().Quo(num, den)

	// lnXReduced = (π * t) / AGM(1, k')
	numLn := newF().Mul(norm.piValue, t)
	lnXReduced := newF().Quo(numLn, norm.agmAGM)

	norm.lnXReduced = lnXReduced

	// lnX = powerOfTwo * ln2 + lnXReduced
	mAsFloat := newF().SetInt64(norm.powerOfTwo)
	mLn2 := newF().Mul(mAsFloat, norm.ln2Value)

	lnX := newF().Add(mLn2, lnXReduced)
	norm.lnX = lnX

	return lnX, nil
}
```

> Note: `agmCore` is the true AGM iteration (Macrobot layer) we already discussed: it takes $(a_0,b_0)$ and iterates until convergence, returning $\operatorname{AGM}(a_0,b_0)$ at the requested precision.
