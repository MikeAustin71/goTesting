## AGM Implementation Plan

### 1. AGM kernel implementation plan

Here’s a concrete, code-oriented roadmap for the AGM kernel, assuming your existing building blocks:

- **Core building blocks you already have**

  - **High‑precision arithmetic:** `*big.Float` with controlled precision via
     `BigFloatHelper.ComputeBigFloatPrecisionBits` / `ComputeBigFloatDecimalDigits`.
  - **Square root:**
    - `BigFloatMath.SqrtBigFloat(x, integerDigits, precBits)`
    - `BigFloatMath.SqrtBigFloatDigits(x, decimalDigits)`
  - **Integer exponent:**
    - `BigFloatMath.IntExpoBigFloat(base, n, precBits)`
    - `BigFloatMath.IntExpoBigFloatDigits(base, n, decimalDigits)`

  For the **AGM kernel itself**, these are sufficient: the iteration only needs addition, division by 2, multiplication, and square root.

#### 1.2. Kernel configuration and signature

Define a core method that performs the **pure AGM iteration**:

```go
// AGM(a0, b0) with given precision; returns AGM(a0, b0) and iteration count.
func (k *agmKernel) AGM(
    a0, b0 *big.Float,
    calculationPrecisionBits uint,
    maxIter uint,
) (agm *big.Float, iter uint, err error)
```

Key points:

- **Inputs:**
  - `a0`, `b0` must be positive `*big.Float` values.
  - `calculationPrecisionBits` chosen via `ComputeBigFloatPrecisionBits` from requested decimal digits.
  - `maxIter` as a safety cap (e.g. 200–400).
- **Outputs:**
  - `agm` as the converged mean.
  - `iter` as the number of iterations actually used.
  - `err` if inputs are invalid (nil, non‑positive, etc.).

#### 1.3. Convergence criterion

Use a simple, precision‑aware stopping rule:

- Let $a_n, b_n$ be the current iterates.
- Stop when $|a_n - b_n| < \varepsilon$, where $\varepsilon$ is tied to the target decimal digits.

For example:

- If the caller wants `D` decimal digits, choose something like
   $$ \varepsilon = 10^{-(D+2)} $$
- Implement as:

```go
// eps = 10^(- (D + 2))
eps := new(big.Float).
    SetMode(big.AwayFromZero).
    SetPrec(calculationPrecisionBits).
    SetFloat64(1.0)

ten := new(big.Float).
    SetMode(big.AwayFromZero).
    SetPrec(calculationPrecisionBits).
    SetFloat64(10.0)

for i := uint(0); i < D+2; i++ {
    eps.Quo(eps, ten)
}
```

Then in the loop:

- Compute `diff = |aNext - bNext|`.
- If `diff.Cmp(eps) <= 0`, declare convergence.

#### 1.4. AGM iteration loop (kernel level)

Inside `agmKernel.AGM`:

- Normalize precision:

```go
workingPrec := calculationPrecisionBits + 16 // small safety margin
newF := func() *big.Float {
    return new(big.Float).
        SetMode(big.AwayFromZero).
        SetPrec(workingPrec)
}
```

- Initialize:

```go
a := newF().Set(a0)
b := newF().Set(b0)
two := newF().SetFloat64(2.0)
```

- Loop:

1. **Arithmetic mean**
    $$ a_{n+1} = \frac{a_n + b_n}{2} $$
2. **Geometric mean**
    $$ b_{n+1} = \sqrt{a_n b_n} $$
    using `BigFloatMath.SqrtBigFloat` or `SqrtBigFloatDigits`.
3. **Convergence check** on $|a_{n+1} - b_{n+1}|$.
4. Stop when converged or `maxIter` reached.

- At the end, round to `calculationPrecisionBits` and return.

### 2. Pseudocode for the true AGM iteration

Below is language‑agnostic pseudocode for the **pure AGM iteration**, matching what you’ll implement in `agmKernel.AGM` and what the math literature calls the “true AGM”:

```text
function AGM(a0, b0, targetDecimalDigits, maxIter):

    # Preconditions:
    #   a0 > 0, b0 > 0
    #   targetDecimalDigits >= 1

    # 1. Compute precision bits and epsilon
    precBits  := ComputeBigFloatPrecisionBits(targetDecimalDigits + safetyDigits, multiplyCount=1)
    workingPrec := precBits + smallSafetyBits

    a := BigFloat(a0, workingPrec)
    b := BigFloat(b0, workingPrec)

    two := BigFloat(2.0, workingPrec)

    # epsilon ~ 10^-(targetDecimalDigits + 2)
    eps := BigFloat(1.0, workingPrec)
    ten := BigFloat(10.0, workingPrec)
    for i from 1 to targetDecimalDigits + 2:
        eps := eps / ten

    iter := 0

    # 2. Main AGM loop
    while iter < maxIter:

        # Arithmetic mean: aNext = (a + b) / 2
        sum   := a + b
        aNext := sum / two

        # Geometric mean: bNext = sqrt(a * b)
        prod  := a * b
        bNext := SqrtBigFloat(prod, integerDigits=0, calculationPrecisionBits=workingPrec)

        # Convergence check: |aNext - bNext| < eps ?
        diff := abs(aNext - bNext)

        if diff <= eps:
            a := aNext
            b := bNext
            break

        a := aNext
        b := bNext

        iter := iter + 1

    # 3. Final result: AGM(a0, b0) ≈ a ≈ b
    # Round to requested precision bits
    agm := BigFloat(a, precBits)  # copy with reduced precision

    return agm, iter
```

In mathematical notation, the iteration is:

- Initialize $a_0 > 0$, $b_0 > 0$.
- For $n \ge 0$: $$ a_{n+1} = \frac{a_n + b_n}{2}, \qquad b_{n+1} = \sqrt{a_n b_n} $$
- The sequence converges rapidly, and the **AGM** is $$ \operatorname{AGM}(a_0, b_0) = \lim_{n \to \infty} a_n = \lim_{n \to \infty} b_n. $$
