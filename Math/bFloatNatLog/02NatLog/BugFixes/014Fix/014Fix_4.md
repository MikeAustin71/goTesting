## 1. AGM identity shape for `agmResultToLn`

We’ll base the kernel on the classical link between the arithmetic–geometric mean and the complete elliptic integral of the first kind:

$$ K(k) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k2 \sin2\theta}} = \frac{\pi}{2,\operatorname{AGM}\bigl(1,\sqrt{1-k^2}\bigr)}. $$

So the **AGM core** we actually compute is:

- Initial values:
  - $a_0 = 1$
  - $b_0 = \sqrt{1 - k^2}$
- Iteration: $$ \begin{aligned} a_{n+1} &= \frac{a_n + b_n}{2}, \ b_{n+1} &= \sqrt{a_n b_n}, \ \operatorname{AGM}(1,\sqrt{1-k^2}) &= \lim_{n\to\infty} a_n = \lim_{n\to\infty} b_n. \end{aligned} $$

Then:

$$ K(k) = \frac{\pi}{2,\operatorname{AGM}(1,\sqrt{1-k^2})}. $$

To turn this into a **natural logarithm**, we choose a fixed, explicit identity of the form:

$$ \ln x = \text{lnOffset}(x) + \text{scaleFactor}(x)\cdot \frac{\pi}{2,\operatorname{AGM}\bigl(1,\sqrt{1-k(x)^2}\bigr)}. $$

Where:

- $x$ is the original argument of $\ln$.
- $x_{\text{norm}}$ is a normalized version of $x$ (range‑reduced).
- $k(x)$ is a modulus derived from $x_{\text{norm}}$.
- $\text{lnOffset}(x)$ is an additive correction term that accounts for:
  - range reduction (powers of $2$ or $e$),
  - and any analytic offset between $\ln x$ and the elliptic expression.
- $\text{scaleFactor}(x)$ is a multiplicative factor (often a simple rational or power‑of‑two factor) that may depend on the normalization.

A concrete, implementation‑friendly choice is:

1. **Range reduction**
    Reduce $x$ to $x_{\text{norm}}$ in a compact interval, e.g. $(1/2, 2)$, via: $$ x = x_{\text{norm}} \cdot 2^m, $$ so that: $$ \ln x = \ln x_{\text{norm}} + m\ln 2. $$

2. **Map $x_{\text{norm}}$ to an elliptic modulus $k$**
    Use a simple, monotone transform such as: $$ k(x_{\text{norm}}) = \frac{x_{\text{norm}} - 1}{x_{\text{norm}} + 1}, $$ which keeps $k$ in $(-1,1)$ for $x_{\text{norm}}>0$.

3. **Define the AGM core**
    $$ a_0 = 1,\quad b_0 = \sqrt{1 - k(x_{\text{norm}})^2},\quad M = \operatorname{AGM}(a_0,b_0). $$

4. **Define the final identity shape**
    We lock in the *structural* identity:

   $$ \boxed{ \ln x = \underbrace{m\ln 2 + \delta(x_{\text{norm}})}_{\text{lnOffset}(x)}

   - \underbrace{\sigma(x_{\text{norm}})}_{\text{scaleFactor}(x)} \cdot \frac{\pi}{2M} } $$

   where:

   - $\delta(x_{\text{norm}})$ is a small, analytic correction term (often expressible in terms of $\ln$ of a simple rational function of $x_{\text{norm}}$),
   - $\sigma(x_{\text{norm}})$ is a simple scaling factor (often $1$, $2$, or a rational function of $x_{\text{norm}}$).

From an **architecture** standpoint, this is enough:

- The AGM kernel only needs to compute $M = \operatorname{AGM}(a_0,b_0)$.
- The **dispatcher + normalization layer** is responsible for:
  - range reduction,
  - computing $k(x_{\text{norm}})$,
  - computing $\lnOffset$ and $\text{scaleFactor}$,
  - and finally combining everything into $\ln x$.

We can refine the exact closed form of $\delta(x_{\text{norm}})$ and $\sigma(x_{\text{norm}})$ later, but the **shape** is now fixed and your data structures can be designed around it.

## 2. `agmNormalizationData` fields (locked to that identity)

Now let’s design `agmNormalizationData` so it matches that identity *exactly* and cleanly separates concerns.

### 2.1. High‑level role

`agmNormalizationData` is the **bridge** between:

- the **dispatcher / normalization layer**, and
- the **AGM kernel**.

It must carry:

1. Everything needed to **run the AGM iteration**:
   - initial $a_0$, $b_0$,
   - precision,
   - and any flags about symmetry or special cases.
2. Everything needed to **convert the AGM result into $\ln x$**:
   - the original $x$,
   - the normalized $x_{\text{norm}}$,
   - the range‑reduction exponent $m$,
   - the precomputed $\ln 2$ factor (or a pointer to it),
   - the scale factor $\sigma(x_{\text{norm}})$,
   - the additive offset $\delta(x_{\text{norm}})$.

### 2.2. Concrete Go struct

Here’s a concrete, “locked‑in” version of `agmNormalizationData` that matches the identity above and fits your existing style:

```go
// agmNormalizationData
//
// Carries all information needed to:
//   1) Normalize x into a form suitable for the AGM kernel,
//   2) Define the AGM initial values (a0, b0),
//   3) Convert the final AGM result M into ln(x) via:
//
//      ln(x) = lnOffset + scaleFactor * (pi / (2 * M))
//
// where:
//   - lnOffset   = m*ln(2) + delta(xNorm)
//   - scaleFactor = sigma(xNorm)
//   - M = AGM(a0, b0).
type agmNormalizationData struct {
    // Original input to ln(x)
    xOriginal *big.Float

    // Normalized argument xNorm in a compact interval (e.g. (1/2, 2))
    // such that xOriginal = xNorm * 2^rangeExponent2.
    xNorm *big.Float

    // Range-reduction exponent m in:
    //   xOriginal = xNorm * 2^rangeExponent2
    // so that:
    //   ln(xOriginal) = ln(xNorm) + rangeExponent2 * ln(2).
    rangeExponent2 int64

    // Elliptic modulus k(xNorm) used to define the AGM core:
    //   k = (xNorm - 1) / (xNorm + 1)
    // and
    //   a0 = 1
    //   b0 = sqrt(1 - k^2).
    kModulus *big.Float

    // Complementary modulus k' = sqrt(1 - k^2), if we want to
    // cache it explicitly (optional but often convenient).
    kPrime *big.Float

    // Initial AGM values:
    //   a0 = 1
    //   b0 = sqrt(1 - k^2) = kPrime
    a0 *big.Float
    b0 *big.Float

    // Precision for the AGM iteration, in bits.
    agmPrecBits uint

    // scaleFactor = sigma(xNorm) in:
    //   ln(x) = lnOffset + scaleFactor * (pi / (2 * M)).
    // Often this will be 1.0, but we keep it explicit so that
    // future variants of the identity can be supported without
    // changing the AGM kernel.
    scaleFactor *big.Float

    // lnOffset = m*ln(2) + delta(xNorm), the additive term in:
    //   ln(x) = lnOffset + scaleFactor * (pi / (2 * M)).
    //
    // This allows us to:
    //   - encode range reduction (m*ln(2)),
    //   - encode any analytic offset between ln(xNorm) and the
    //     elliptic expression.
    lnOffset *big.Float

    // Cached constants (optional but convenient):
    //   - pi:      π to the required precision,
    //   - ln2:     ln(2) to the required precision.
    // These can be shared or injected from a higher-level
    // constants subsystem.
    pi  *big.Float
    ln2 *big.Float
}
```

## 3. How `agmResultToLn` uses this struct

With that struct in place, the **conversion function** becomes extremely simple and stable:

```go
// agmResultToLn
//
// Given:
//   - agmData: fully-populated agmNormalizationData
//   - M:       AGM(a0, b0) computed by the AGM kernel
//
// computes:
//   ln(xOriginal) = lnOffset + scaleFactor * (pi / (2 * M)).
func (nlMac *naturalLogAGMMacrobot) agmResultToLn(
    agmData *agmNormalizationData,
    M *big.Float,
) *big.Float {

    // tmp := pi / (2 * M)
    tmp := new(big.Float).
        SetMode(big.AwayFromZero).
        SetPrec(agmData.agmPrecBits)

    two := new(big.Float).
        SetMode(big.AwayFromZero).
        SetPrec(agmData.agmPrecBits).
        SetFloat64(2.0)

    denom := new(big.Float).
        SetMode(big.AwayFromZero).
        SetPrec(agmData.agmPrecBits).
        Mul(two, M)

    tmp.Quo(agmData.pi, denom)

    // tmp = scaleFactor * (pi / (2 * M))
    tmp.Mul(tmp, agmData.scaleFactor)

    // result = lnOffset + tmp
    result := new(big.Float).
        SetMode(big.AwayFromZero).
        SetPrec(agmData.agmPrecBits).
        Add(agmData.lnOffset, tmp)

    return result
}
```

Where:

- `agmNormalizationData` is prepared by the **dispatcher + normalization layer**:
  - it sets `xNorm`, `rangeExponent2`, `kModulus`, `a0`, `b0`, `scaleFactor`, `lnOffset`, `pi`, `ln2`, and `agmPrecBits`,
- the **AGM kernel** only cares about:
  - `a0`, `b0`, `agmPrecBits`,
- and `agmResultToLn` is a pure, deterministic mapping from `(agmData, M)` to `ln(xOriginal)` using the locked identity:

$$ \ln x = \lnOffset + \text{scaleFactor}\cdot \frac{\pi}{2M}. $$
