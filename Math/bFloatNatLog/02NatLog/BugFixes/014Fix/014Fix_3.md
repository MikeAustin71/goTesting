# **Proposing Go Method Signatures for the AGM Algorithm**

## Logic

I’m thinking of proposing the following Go signatures:

In `naturalLogAGM.go`, I’ll define `NaturalLogAGM` with a method `LnAGM` for calculating the natural log. In the dispatcher file, `NaturalLogDispatcher` will handle the algorithm selection, with `Ln` as the method. The kernel in `naturalLogAGMMacrobot.go` will have `agmKernel` for the AGM computation, and the Nanobot will handle iteration with `agmIterate`. I’ll also mention that we’re working in the `big.Float` domain, so no need for LCD/fraction simplification. I'll keep the math minimal. You’re building something really clean here, so let’s keep the wiring crisp and explicit.

------

### Quick note on “lowest common denominator” / fraction simplification

For the AGM-based natural log in your current design (all `*big.Float`), you do **not** need:

- **Lowest common denominator operations**, or
- **Fraction simplification (rational reduction)**

All normalization, scaling, and iteration can be done directly in `*big.Float` space (using your existing `BigFloatMath` helpers for `SqrtBigFloat`, `IntExpoBigFloat`, etc.). If you later introduce a rational layer, that’s a separate concern.

```go
package naturalLogCalcs

import (
	"math/big"
	ePref "github.com/MikeAustin71/errpref"
)

type NatLogAlgorithm int

const (
	NatLogAlgoAGM NatLogAlgorithm = iota
	NatLogAlgoTaylor
	// Future: NatLogAlgoNewton, etc.
)

type NaturalLogDispatcher struct{}

func (d *NaturalLogDispatcher) Ln(
	x *big.Float,
	calculationDecimalDigits uint,
	algo NatLogAlgorithm) (*big.Float, error) {

	ePrefix, err := ePref.ErrPrefixDto{}.NewIEmpty(
		nil,
		"NaturalLogDispatcher.Ln()",
		"")
	if err != nil {
		return new(big.Float), err
	}

	switch algo {
	case NatLogAlgoAGM:
		return new(NaturalLogAGM).LnAGM(x, calculationDecimalDigits, ePrefix)

	case NatLogAlgoTaylor:
		// Existing Taylor implementation (already present today)
		return new(NaturalLogTaylor).LnTaylorDirect(x, calculationDecimalDigits, ePrefix)

	default:
		return nil, &FuncReturnError{
			ErrPrefix:  ePrefix.String(),
			ReturnFunc: "NaturalLogDispatcher.Ln(x, calculationDecimalDigits, algo)",
			ErrContext: "Unsupported natural log algorithm.",
			ErrMessage: "Unknown NatLogAlgorithm value.",
		}
	}
}
```

### 3. Macrobot: AGM kernel orchestration

#### naturalLogAGMMacrobot.go

```go
package naturalLogCalcs

import (
	"math/big"
	ePref "github.com/MikeAustin71/errpref"
)

type naturalLogAGMMacrobot struct{}

// lnAGMKernel
//
// High-level AGM kernel for ln(x).
// 1) Normalizes x into a suitable range
// 2) Sets up initial AGM pair (a0, b0)
// 3) Calls the true AGM iteration
// 4) Applies the final ln(x) formula from the AGM result
func (agmMacro *naturalLogAGMMacrobot) lnAGMKernel(
	x *big.Float,
	calculationDecimalDigits uint,
	errPrefDto *ePref.ErrPrefixDto) (*big.Float, error) {

	ePrefix, err := ePref.ErrPrefixDto{}.NewFromErrPrefDto(
		errPrefDto,
		"naturalLogAGMMacrobot.lnAGMKernel()",
		"")
	if err != nil {
		return new(big.Float), err
	}

	// 1. Normalize x and derive scaling parameters
	normData, err := new(naturalLogAGMNanobot).normalizeInputForAGM(
		x,
		calculationDecimalDigits,
		ePrefix)
	if err != nil {
		return nil, err
	}

	// 2. Build initial AGM pair (a0, b0)
	a0, b0, precBits, err := new(naturalLogAGMNanobot).buildInitialAGMPair(
		normData,
		calculationDecimalDigits,
		ePrefix)
	if err != nil {
		return nil, err
	}

	// 3. Run the true AGM iteration
	agmValue, iterCount, err := new(naturalLogAGMNanobot).agmKernelIterate(
		a0,
		b0,
		precBits,
		ePrefix)
	if err != nil {
		return nil, err
	}

	// 4. Convert AGM result into ln(x) using the chosen AGM formula
	lnX, err := new(naturalLogAGMNanobot).agmResultToLn(
		agmValue,
		normData,
		calculationDecimalDigits,
		precBits,
		iterCount,
		ePrefix)
	if err != nil {
		return nil, err
	}

	return lnX, nil
}
```

- Macrobot is the **orchestrator**: normalization → AGM iteration → final ln(x) formula.
- All heavy math is delegated to Nanobot/Molecule/Atom… layers.

### 5. Molecule/Atom/…: low-level math primitives

These are the “lego bricks” used by Nanobot.

#### naturalLogAGMMolecule.go

```go
package naturalLogCalcs

import (
	"math/big"
	ePref "github.com/MikeAustin71/errpref"
)

type naturalLogAGMMolecule struct{}

// arithmeticMean
func (agmMol *naturalLogAGMMolecule) arithmeticMean(
	a, b *big.Float,
	precBits uint) *big.Float {

	// (a + b) / 2
	return new(big.Float).
		SetMode(big.AwayFromZero).
		SetPrec(precBits).
		Quo(
			new(big.Float).Add(a, b),
			new(big.Float).SetFloat64(2.0),
		)
}

// geometricMean
//
// Uses your BigFloatMath.SqrtBigFloat for sqrt(a*b).
func (agmMol *naturalLogAGMMolecule) geometricMean(
	a, b *big.Float,
	precBits uint,
	errPrefDto *ePref.ErrPrefixDto) (*big.Float, error) {

	product := new(big.Float).
		SetMode(big.AwayFromZero).
		SetPrec(precBits).
		Mul(a, b)

	return new(BigFloatMath).SqrtBigFloat(product, 0, precBits)
}
```

### 6. True AGM iteration pseudocode (for `agmKernelIterate`)

Here’s the core iteration logic that will live in `naturalLogAGMNanobot.agmKernelIterate` and call Molecule/Atom helpers:

```text
function agmKernelIterate(a0, b0, precBits):

    a ← a0
    b ← b0

    maxIter ← some function of precBits (e.g., O(log precBits))
    i ← 0

    loop:
        if agmConverged(a, b, precBits) or i ≥ maxIter:
            break

        aNext ← arithmeticMean(a, b, precBits)
        g     ← geometricMean(a, b, precBits)  // sqrt(a*b) via BigFloatMath

        a ← aNext
        b ← g

        i ← i + 1

    // At convergence, AGM(a0, b0) ≈ a ≈ b
    return a, i
```

In Go terms, that’s exactly what `agmKernelIterate` will do, using:

- `naturalLogAGMMolecule.arithmeticMean`
- `naturalLogAGMMolecule.geometricMean` (which uses `SqrtBigFloat`)
- `naturalLogAGMAtom.agmConverged`
