------

# **2. Why the Taylor Series Needs a Safety Margin**

The Taylor series you are using is:

$$ \ln(m) = 2\left(t + \frac{t3}{3} + \frac{t5}{5} + \cdots\right), \qquad t = \frac{m-1}{m+1} $$

This is an **alternating, rapidly convergent series** when $m$ is near 1.

But here’s the catch:

### **The series terms shrink geometrically in powers of $t^2$,

not in powers of 2.**

So the magnitude of the next term is not directly comparable to:

- the binary precision (`prec` bits), or
- the decimal precision (digits of expected output)

This means:

- If you stop *too early*, the last term you skipped is still large enough to affect the final rounded value.
- If you stop *too late*, you waste time but do not improve accuracy.

Thus, the stopping criterion must be:

> **Stop when the next term is smaller than the rounding noise floor
>  \*by at least one extra digit\*.**

This is exactly what MPFR, GMP, and Boost.Multiprecision do internally.

------

# **3. Why “one extra decimal digit” ≈ “4 extra bits”**

One decimal digit corresponds to:

$$ \log_2(10) \approx 3.321928 $$

So:

- 1 extra decimal digit ≈ 3.3 bits
- 2 extra decimal digits ≈ 6.6 bits

Thus your intuition:

> “Add a safety buffer of about 4 bits”

is mathematically correct.

------

```go

It forces the loop to continue until the next term is *astronomically* small — much smaller than needed — but ironically, because of floating‑point rounding, the loop actually stops *too early* for values near 1.

This is why:

- ln(3237) works

- ln(1.0001) fails

Values near 1 require **more terms**, not fewer.

------

# **5. The Correct Fix**

You want the loop to stop when:

$$ | \text{next term} | < 2^{-(\text{prec} + \text{safety})} $$

Where:

- `prec` = target precision in bits
- `safety` = 4 bits (≈ 1 extra decimal digit)

# **`naturalLogTaylor_mechanics.go` (Corrected Version)**

package naturalLogCalcs

import "math/big"

type naturalLogTaylorMechanics struct{}

// lnTaylorCore computes ln(m) for m in (0, 2] using the
// atanh-style series:
//
//   t = (m - 1) / (m + 1)
//   ln(m) = 2 * (t + t^3/3 + t^5/5 + ...)
//
// It assumes m > 0 and uses workPrec bits.
func (nlTaylorMech *naturalLogTaylorMechanics) lnTaylorCore(m *big.Float, workPrec uint) *big.Float {

	nlShared := new(naturalLogShared)

	one := nlShared.newFloat(workPrec)
	one.SetFloat64(1.0)

	two := nlShared.newFloat(workPrec)
	two.SetFloat64(2.0)

	// t = (m - 1) / (m + 1)
	num := nlShared.newFloat(workPrec)
	den := nlShared.newFloat(workPrec)

	num.Sub(m, one)
	den.Add(m, one)

	t := nlShared.newFloat(workPrec)
	t.Quo(num, den)

	// term = t
	term := nlShared.newFloat(workPrec)
	term.Set(t)

	// sum = t
	sum := nlShared.newFloat(workPrec)
	sum.Set(t)

	// t2 = t^2
	t2 := nlShared.newFloat(workPrec)
	t2.Mul(t, t)

	// k = 1, next denominator = 3, 5, 7, ...
	k := int64(1)

	// --------------------------------------------------------------------
	// Corrected stopping criterion:
	//
	// Stop when |next term| < 2^(-(prec + 4))
	//
	// This ensures the Taylor series runs one decimal digit beyond the
	// target precision (≈ 4 bits of safety), preventing premature exit
	// for values near 1.
	// --------------------------------------------------------------------
	eps := nlShared.newFloat(workPrec)
	eps.SetFloat64(1.0)
	eps.SetMantExp(eps, -int(workPrec-64+4))
	// Explanation:
	//   workPrec = prec + 64
	//   We want threshold = 2^(-(prec + 4))
	//   So exponent = -(workPrec - 64 + 4)

	absTerm := nlShared.newFloat(workPrec)

	for {
		// term *= t^2
		term.Mul(term, t2)

		// k += 2
		k += 2

		// term / k
		denomK := nlShared.newFloat(workPrec)
		denomK.SetInt64(k)

		tmp := nlShared.newFloat(workPrec)
		tmp.Quo(term, denomK)

		// sum += term/k
		sum.Add(sum, tmp)

		// |term/k|
		absTerm.Abs(tmp)
		if absTerm.Cmp(eps) <= 0 {
			break
		}
	}

	// ln(m) = 2 * sum
	lnm := nlShared.newFloat(workPrec)
	lnm.Mul(two, sum)

	return lnm
}
```
